# BOLT 11 test vectors

`invoice-test.json` is a verbatim copy of the machine-readable BOLT 11 invoice vectors added by
[lightning/bolts#1357](https://github.com/lightning/bolts/pull/1357) ("bolt11: reject duplicate payment hashes in
invoices"), which also adds the reader rule "MUST fail the payment if more than one `p` field is present" (NL-516).

- Upstream commit: `03ac8145d140d1cdd54ada23d7779d3483e6a9c5` (PR head, not yet merged into master; fetched 2026-09-28)
- Source: `https://raw.githubusercontent.com/lightning/bolts/03ac8145d140d1cdd54ada23d7779d3483e6a9c5/bolt11/invoice-test.json`
- SHA-256: `959658cf2fc00a793c6e30efa22f1ac80e059e4fe88fcdf72c99c8a6741b71d9`

Each entry has `description`, `invoice` and `valid`; there are no expected field values. The file covers every example
of `11-payment-encoding.md` at that commit, including the new invalid cases "Two distinct p fields in an otherwise
valid invoice" and "The same p field twice in an otherwise valid invoice".

Do not edit this file. To refresh it, re-download from a newer upstream commit (the path is `bolt11/invoice-test.json`
once the PR is merged) and update the SHA above. The tests are in `Models/InvoiceSpecVectorTests.cs`.
